# THE NET PHANTOM — Screen props

KMPU3432 Assignment 2 · Category 3: Workplace Integrity · Pure front-end, no backend or API.

Open these directly in a browser (double-click), or use the switcher bar at the top of each page:

| File | Screen |
|---|---|
| `1-stock.html` | Trading terminal: stock chart, ORDER FILLED +28%, margin call, balance RM 10.01 |
| `2-implant.html` | Settlement console: TX #99021 −RM 0.01, EXECUTE SCRIPT? YES / NO, accumulated diversion |
| `3-auditor.html` | Audit findings: RM 250k total, flagged ledger rows, CCID referral |
| `index.html` | Index of all three screens |

All numbers come from `shared/data.js`, so the screens stay consistent with each other and with the script.
Each screen has a step button (Next scene / Run settlement / Reveal findings) and a Reset button.
Everything is simulated: no real trading, banking or settlement is involved.
